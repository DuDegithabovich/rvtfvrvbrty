# Random Quote Generator

## Автор
**Имя:** Зимницкий Михаил 

## Описание
Приложение для генерации случайных цитат с сохранением истории, фильтрацией и возможностью добавления новых цитат. Разработано на Python с использованием Tkinter для графического интерфейса.

## Функциональные возможности
- ✅ Генерация случайных цитат из предопределенного списка
- ✅ Фильтрация цитат по автору и теме
- ✅ Сохранение истории сгенерированных цитат в формате JSON
- ✅ Добавление новых цитат с проверкой корректности ввода
- ✅ Очистка истории
- ✅ Красивый и интуитивно понятный интерфейс
- ✅ Автоматическая загрузка сохраненной истории при запуске

## Технологии
- Python 3.8+
- Tkinter (GUI)
- JSON (хранение данных)
- random (генерация случайных цитат)
- Git (система контроля версий)
